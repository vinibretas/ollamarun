# Editor

Ctrl+G opens `$OLLAMA_EDITOR` on the current REPL input: write or edit the
prompt in your editor, and it comes back to the input buffer when you save and
exit. In the deprecated [TUI](../tui/index.md) the same key opens `$EDITOR`;
`/edit` reopens the last message for editing instead — see
[Undo, retry and edit](sessions/undo-retry-edit.md).
