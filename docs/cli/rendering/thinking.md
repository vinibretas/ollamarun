# Thinking panel

Thinking streams live and is collapsed by default as an animated
`thinking · N chars · Ctrl+T to expand` line. Ctrl+T expands a tail-capped
boxed preview in place (press again to collapse; the stream never pauses),
and `/thinking full` prints the stored panel later. `--show-thinking`/
`--hidethinking` and config `thinking` set the start mode.
