    ollamarun¶

    A terminal agent harness for Ollama — a personal project about how far local models go when you hand them tools.

    ollamarun began as a nicer ollama run: streamed markdown, 2D Unicode math, sessions that actually persist. It has since grown into a full harness — an approval-gated tool loop, two front ends, remote inference, context/GPU placement fitting, and an HTTP API layer (ollamarun serve) that speaks both the OpenAI API and its own native agent API.

    Every ollama run flag (ollama 0.34) is accepted and extended, so it still doubles as a drop-in replacement for the CLI it started as.

    Quickstart¶

    Needs Linux, Python 3.10+ and a reachable Ollama server (default 127.0.0.1:11434).

    $ pip install --user rich requests prompt_toolkit
$ ./ollamarun qwen3:8b "explain this repo"    # one-shot
$ ./ollamarun qwen3:8b                        # interactive REPL

    Status¶

    Early, single-developer and moving. Built against one Linux box and a small Tailscale fleet; Python 3.10; a few tools are wired to my own side projects and degrade gracefully when those are absent. Rough edges are part of the deal — expect the structure to keep changing as the learning continues.
